# 02_methodology

Материалы по детекторам точек разладки, штормовых зон и Variability.
Остальные слои проекта (`00_prep`, EDA, дашборд) — либо вход, либо
потребитель того, что здесь проверено.

## Задача

`ruptures.Pelt` по истории прослушиваний даёт 7 точек разладки. Один
период, который помнится как переломный, в список не попал.

Вместо выбора «верить алгоритму» или «не верить» — независимая проверка.
Ответ: алгоритм не ошибся, он искал сдвиг не в том признаковом
пространстве. Поэтому пайплайн пересобран: вместо одного детектора —
четыре слоя точек и отдельная ось Variability.

## 12 фаз

| # | Фаза | Что проверялось | Исход |
|---|---|---|---|
| 1 | Наивный старт | `pen=10` + 7 смешанных признаков | ❌ сломалось |
| 2 | Bootstrap | Устойчивость точек к пересэмплированию | 🔄 зоны, не точки |
| 3 | Cosine | Смена артистов при похожем звуке | ✅ подтвердилось |
| 4 | Разделение слоёв | Звук и поведение — один процесс | ✅ два разных |
| 5 | Периодизация | Стабильные эпохи между точками | ❌ 0 из 6 |
| 6 | Self-percentile | Свой ранг как уровень | ❌ структурно невозможен |
| 7 | Noise-floor | Permutation-нуль для Variability | ✅ работает |
| 8 | Разные нули | Один null на все признаки | 🔄 свой под структуру |
| 9 | Detrend | Корреляции осей | 🔄 2 не установлены |
| 10 | Behavior в компас | Связь с Burnout | ⚠️ не входит |
| 11 | Toolkit | Обобщение в модуль | ✅ `VariabilityAnalyzer` |
| 12 | ALL vs VALID | Одна база для всего | 🔄 по семантике |

## Финальная архитектура

Четыре слоя точек:

| Слой | База | Метод | Точки |
|---|---|---|---|
| PELT-A (звук) | valid + trimmed | PELT, L2, BIC-штраф | `2023-09`, `2024-02`, `2024-07` |
| PELT-B (поведение) | all + trimmed | PELT, L2, BIC, сглаживание | `2021-08`, `2024-02`, `2024-12`, `2025-10`, `2026-03` |
| Cosine (артисты) | all + trimmed | косинусное расстояние, MAD-пики | `2021-02`, `2022-05`, `2024-02` |
| Storm (зоны) | all + trimmed | rolling std + биномиальный тест | `2021-01..2021-06`, `2023-10..2024-05` |

Отдельно — ось компаса Sound Variability: доля значимых месячных сдвигов
в окне 12 мес. Lifetime `0.417` (Medium), Current `0.083` (Low). База —
valid.

`2024-02` — единственная дата, видимая всеми тремя слоями точек.

## Компас

Четыре оси: Discovery, Retention, Burnout, Sound Variability. Оси
построены на разных данных. Проверка в фазе 9: сильной парной связи не
обнаружено. «Независимы» здесь означает «сильной связи не нашли», а не
математическую ортогональность.

## Приложения A/B/C

Только в ноутбуке. В основной нарратив не входят, но обосновывают
решения внутри фаз.

| Приложение | Тема | Итог |
|---|---|---|
| A | SNR | Не критерий сигнала (permutation опроверг) |
| B | Cut-scan + Storm | Точки PELT/Cosine не концентрируются в штормах (`p = 0.66`) |
| C | Permutation-null для Cosine | Не работает для категориальных (`69 из 69` значимы) |

## Приложение в `PELT_JOURNEY.md`

Только в текстовом файле: сравнение 7 точек примитивного детектора из
`01_data_analysis/03_eda_behavioral.ipynb` с финальными слоями. Пять из
семи совпадают ±1 мес, одна подтверждена через Cosine, одна не
подтверждается нигде. Финальная архитектура добавляет три точки, которых
примитивный метод не видел.

## Потребители

Ноутбук ничего не пишет. Результаты попадают в дашборд через
`03_dashboard/dashboard_data_prep.ipynb`, который вызывает те же модули

## Запуск

1. 01_data_analysis/00_prep/ должен отработать — в data/00_output/ лежат готовые паркеты. Методология читает через load_all 6 из них: eda_ready, tracks_exportify, playlist_links, library_tracks, owner_ids, playlists_metadata.
2. `jupyter notebook 02_methodology/time_detector_experiments.ipynb`
3. `Restart & Run All`. Порядок ячеек обязателен: фаза 9 использует
   `var_sound` из фазы 7 и `var_beh` из фазы 8.
4. Ячейка 0.1 сама находит `src/` вверх по дереву. Если падает с
   `FileNotFoundError` — проверить, что `src/paths.py` и `src/loaders.py`
   на месте.

Ноутбук читает данные и печатает выводы. Файлы в `data/` и
`03_dashboard/` не пишет.

## Ограничения

- Пороги double-gate (p99 null, ≥2 признака, p75 практический) —
  эвристики, откалиброванные на этих данных. Для другого профиля могут
  потребовать перекалибровки.
- N=1. Принципы к другим профилям не проверялись.
- Permutation-null не работает для категориальных признаков высокой
  кардинальности. Это факт метода, не открытый вопрос.
- Компас — описательная рамка, не статистическое утверждение.
- `Behavior Var ↔ Burnout = −0.757` после детренда — единственная
  функциональная связь во всём анализе. Bootstrap ей не делался,
  поправка на множественность не применялась.
- Sound Variability lifetime `0.417` совпадает с `null_high = 0.417`.
  Метка в дашборде — по фиксированным порогам 0.3 / 0.5.
